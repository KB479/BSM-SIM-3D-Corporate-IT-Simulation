# 📸 Prototype Visuals & UI Disclaimer

This directory contains screenshots from the **Minimum Viable Product (MVP)** stage of the BSM-SİM project.

### ⚠️ UI Asset Disclaimer
Certain graphical user interface (GUI) elements visible in these screenshots—such as specific operating system wallpapers, IDE icons, and email client logos—are **temporary placeholder assets**. They were implemented strictly for rapid prototyping and to establish familiarity during early testing phases. 

A comprehensive visual overhaul is planned for the development roadmap, and all placeholder graphics will be entirely replaced with original or open-source alternatives in the final deployment.
